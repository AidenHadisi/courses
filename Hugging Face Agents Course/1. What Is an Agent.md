# What Is an Agent?

[Course page](https://huggingface.co/learn/agents-course/unit1/what-are-agents)

An **agent** is a system that uses an AI model to reason, plan, and interact with its environment to achieve a user-defined goal. Its environment can be physical or digital. **Agency** describes its ability to act within that environment.

For example, Alfred receives “bring me a coffee,” works out the steps, uses the coffee machine, and brings back the coffee. The user supplies the goal; the agent decides how to carry it out using its available capabilities.

## Model and capabilities

- **Brain — the AI model:** interprets instructions, reasons about the situation, plans, and chooses actions.
- **Body — capabilities and tools:** provides the means to gather information and execute those actions.

The model is one part of the agent. What the whole system can do depends on the capabilities it has been given.

The course focuses on **large language models (LLMs)**, which process and generate text. Other models can serve as the brain too: a **vision-language model (VLM)** can also interpret images.

## How tools enable actions

A text-generating model can describe an action or request a function call. The surrounding software executes the tool that interacts with the environment.

For example, an email tool could expose this Python function:

```python
def send_message_to(recipient, message):
    """Send an email message to a recipient."""
    ...
```

For “ask my manager to postpone today's meeting,” the model could choose:

```python
send_message_to("Manager", "Can we postpone today's meeting?")
```

Likewise, a chat application can generate an image by letting its model invoke an image-generation tool.

**Tools are capabilities; actions are what the agent does with them.** An action can involve multiple tools. Tool design strongly affects agent quality: some tasks need a specific capability such as sending email, while others can use a general tool such as web search.

## Spectrum of agency

Agency increases as the model controls more of the program's behavior:

1. **Simple processor:** produces output without deciding the program's path.
2. **Router:** chooses which predefined path runs next.
3. **Tool caller:** chooses a function and its arguments.
4. **Multi-step agent:** chooses successive actions and decides whether to continue or stop.
5. **Multi-agent workflow:** can start another agentic workflow. The course places this at the same agency level as a multi-step agent.

## Applications

- **Personal assistants:** retrieve information, set reminders, send messages, or control smart devices.
- **Customer service:** troubleshoot problems, create support tickets, or complete transactions toward service goals.
- **Game NPCs:** respond to player actions and context with more flexible behavior and dialogue.
